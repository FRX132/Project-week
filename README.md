## Overview

A full-stack meal-planning web application developed as a team project. The platform helps users discover meal ideas, browse recipes, and plan meals through a structured web interface.


Key learning outcomes: team coordination, collaborative Git workflows, PHP development, database integration, form handling, and building a practical end-to-end web application.

## Demo / Deployment
Live demo: https://ozge-kolay.codefactory.live/projects/Meal-planner/Pages/landingPage.php

## Key Features

- Browse meals and recipes
- View meal details and ingredients
- Organize meals through a meal-planning interface
- User-friendly navigation and responsive page layout
- Dynamic content managed with PHP
- Form handling and user input validation
- Stored application data with MySQL
- Collaborative development using Git and GitHub



## Tech Stack

    Backend: PHP
    Database: MySQL
    Frontend: HTML/CSS/JavaScript
    Version control: Git and GitHub
